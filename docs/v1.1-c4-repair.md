## 2. What was built

Production changes are confined to `src/StorageInventory.Library/`; no other first-party assembly changed.

| Area | Change |
|---|---|
| Schema | `name (name_id, source_id NOT NULL REFERENCES source, utf16, UNIQUE (source_id, utf16))` (D-52); the object list is unchanged; `Schema1Fingerprint` re-pinned to `1d1a977f…e90922`. The old value `8f96f561…` was reproduced exactly by an independent script before the new one was frozen |
| Importer | name cache per source (`Intern(lease, name)`); both verification statements and invariant 4 take the source id; `run_id` is compared in the verification and in the publishing statement; cancellation checked every 4,096 inserted rows, once immediately before `COMMIT`, and inside verification; IMP-11 hook (`ISpaceGuard`, `SpaceCheck`, pending growth Λ, `DictionaryFootprint`) |
| Cancellation | `CancellationScope` with a SQLite progress callback (20,000 opcodes) that is removed with its scope and touches no other connection |
| Interlock and leases | `default`, foreign, stale, disposed, handed-off and wrong-kind leases are refused by every writer operation before any I/O; `RunStartup`/`TryRunMutation` hand the lease to callers as a parameter; class C is reported from every mutation (T-CREATE, T0, T-OUTCOME, T-IMPORT, T-DELETE, set-aside, release of a writer) |
| State machine | `application_id = 0`, `user_version = 0`, no schema objects (a 108-byte read of page 1) is **uninitialised** and initialised by the next save; a non-empty journal beside it is Leftover files and is never played back; the gate is taken around open, create and recovery; path validation and the header check are repeated before every writer open |
| Lock-first | every member accessor of `LibraryStore` throws without the writer lock; the member paths are private |
| Audits | A-25 is rewritten to the frozen wording over every first-party assembly; A-26 judges side-file events by lease kind with no margin; the constant-SQL audit requires every field of `Sql/*.cs` to be `const` and checks the forwarders |
| TEST-P1 | `tests/StorageInventory.Library.Tests/PerfGate/` and `tests/perf/`: generator port, workload-class function, run records with mandatory attribution fields, four cancel points, kill at the journal's peak, negative control, fail-closed attribution (`attribute_run.py` wrapping the reference `journal_ranges.py`, vendored unmodified), whole-machine load source with job-object accounting, session orchestrator with a manifest declared first, and report generator. See `tests/perf/README.md` |
